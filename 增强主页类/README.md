# 增强主页类 — 界面 / 主页增强

存放对 DSH 网页界面、主页、交互体验的**自写改造**。

## 现有内容

| 子目录 | 说明 |
|---|---|
| `dsh-mods/` | 本机 DSH 界面自定义补丁集：费用预估与账单明细、余额查询、会话完成提醒、粘贴图片转文字、Token 用量统计等 6 个功能（按功能组织） |

## 约定

- 界面类改造（补丁、样式、组件、设计规范）统一归档在本目录；
- 新增强功能时按 `dsh-mods/features/` 的「一个功能一个名字」方式组织，并在 `dsh-mods/README.md` 功能清单登记；
- 设计语言规范见 `dsh-mods/UI-GUIDE.md`。
