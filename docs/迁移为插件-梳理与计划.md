### 1.3 已知痛点(迁移动机)

1. **升级即失效**:`dsh` 升级整体替换 `node_modules`,补丁全部丢失,需重跑 `reapply-dsh-mods.sh` + 重启服务;
2. **上游漂移**:补丁基于编译产物行号,上游代码一变就 `patch` 失败需手动合并;
3. **宿主内代码与产品逻辑耦合**:如 `dsh-client-runtime`、`dsh-client-ui-conversation` 被直接改动;
4. **与本机互斥**:补丁修改的是本机安装包,换机器/换会话无法复用,只能从仓库拷贝重放。

## 二、迁移目标

把 A/B/C/E/F 五个功能重写为**动态 Cordis 插件**(Host/Client 双端,`cordis_define` 定义、会话内运行、可随时 stop/update),源码归档 `插件类/<pluginId>/`;D(usageOnly)作为宿主内部优化给出结论。迁移完成后,补丁集可整体退役(`--revert`),功能由插件承载。

## 三、迁移可行性矩阵(依据当前运行时 Inspect 目录)

| 功能 | 平台 | 需要的运行时能力 | 迁移路径 | 可行性 | 主要风险/难点 |
|---|---|---|---|---|---|
| A 余额查询 | Host+Client | `credentials.resolve("DEEPSEEK_API_KEY")` + `web.fetch` + `harness.handle`(RPC)+ Client Slot(余额卡片) | Host 注册 `balance` RPC 调 DeepSeek `/user/balance`;Client 在 `conversation.session.header.utilities` 或 `settings.general.item` 渲染余额 | ✅ 高 | 无 `process.env` 全局;密钥走 credentials 服务(已确认 `credentialRef` 即品牌字符串,直接传名字) |
| B 会话完成提醒 | Host+Client | Host `agent/status` / `agent/turn-stopping` 事件;Client 轮询 `host.call` 状态;`settings.section` 设置页;Audio/标题(浏览器全局,需守卫) | Host 监听 agent 状态缓存每会话 running 状态;Client 定时轮询检测 idle→running→idle,弹提醒卡 + 播放音 + 动态标题 | ✅ 高 | Client 端无 host→client 推送,需轮询(1s 间隔,本地 RPC 开销小);浏览器全局(Audio/localStorage/document)需运行时守卫,若 Guard 拦截则降级为 React `<audio>` |
| C 费用预估与账单明细 | Host+Client | Client `conversation.composer.dock`(预估卡片,提供 `useProjection`/`useSession`/`ConversationSnapshot`)、`conversation.chat.turnTail`(每轮柱状图/折叠预览)、`settings.section`(总账单页,id 避开补丁已占的 `billing` → 用 `billing-v2` 或等补丁退役后复用)、`shell.overlay`/`conversation.input.overlay`(账单明细弹窗);Host RPC 聚合全会话费用(`sessionQuery.listEvents` + 价格表) | 最大移植:补丁 197KB 的 UI 组件全部改为 Slot 注册的 React 组件;费用数据优先从 `useProjection`(tokenUsage 投影)取,账单明细/总账单走 Host RPC 聚合 | ⚠️ 中(工作量大) | 补丁 UI 与插件 UI 并存期会重复渲染(需停用补丁或插件选不同 slot id);`ConversationSnapshot` 字段需按子代理精读报告确认;柱状图/分页/弹窗交互全部重写 |
| D 账单接口优化(usageOnly) | Host 内部 | 无对应插件钩子(查询路径在宿主内部,无 waterfall/Service 可拦截) | **不可迁移为插件**。但迁移 C 后,费用 UI 改走投影/RPC 聚合,不再拉全量会话历史,usageOnly 的动机消失 → 补丁可整体退役;若需保留(其他调用方),维持 reapply | ❌ 不可迁移 | — |
| E 粘贴图片转文字 | Host | `agent/pre-step` waterfall(可替换进入该步的 messages)+ `web.fetch`(GLM)+ 内存缓存(sha256 需内置实现,无 crypto 全局)+ 密钥 | 监听 `agent/pre-step`,把 user message 中 image 块替换为 GLM 文字描述(8s 超时、sha256 前 24 位缓存、无 key 时降级占位文案);改写后 DeepSeek 适配器不再收到 image 块,`dsh-llm-deepseek.patch` 可退役 | ✅ 高 | `agent/pre-step` payload 的 message/content 结构需按子代理报告确认(image 块字段、替换返回的 PreStepDecision 形态);GLM 密钥从 credentials(`ZHIPU_API_KEY`)或 fs 读 `~/.dsh/.env` |
| F Token 用量统计 | Host | `sessionProjections.register(definition)`(已确认 Service 存在,注册即 effect) | 将补丁中的 `tokenUsageByModelProjectionDefinition` 改为注册到 `sessionProjections`(键 `tokenUsageByModel`),状态保持普通对象(修复版);Client 经 `useProjection` 或 Host RPC 读取 | ✅ 高 | 投影定义对象结构需按子代理报告精确复刻(init/apply/stateVersion/schema);键名需与宿主 map 兼容(运行时按字符串键注册) |
| G cfgf-1 | — | 已是动态插件 | 无需迁移;作为插件模式样板 | ✅ 已完成 | — |

## 五、约定

- 每个插件按 `插件类/<pluginId>/`(README.md + host.js + client.js)归档;
- 密钥一律走 `credentials` 服务或 `~/.dsh/.env`,源码内不出现真实密钥;
- 提交前 `bash scripts/check-secrets.sh --all`;
- 插件生命周期:stop 保留定义,undefine 仅确认不再需要后执行。
